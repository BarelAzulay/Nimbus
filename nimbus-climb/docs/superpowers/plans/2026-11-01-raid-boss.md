# Boss raids: always there, hard at every tier — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One raid boss always stands on the colosseum floor; walking through the back gate puts a player into the fight for their tier (Starter / Mid / High / Max by the highest pet on the active team, a dare picks a higher one), the boss is brutal at every tier (solo ~5%, 3 teams ~40%, 8 teams ~85%), enrages at 30% health with a lethal telegraph, pays Gold / Silver / Bronze by damage share scaled per tier at most once per 20 minutes per player (saved across servers), and the Join button, window, announcement and schedule are gone.

**Architecture:** Five tasks on branch `raid-boss` (worktree `Projects Main\Nimbus\.worktrees\raid-boss\nimbus-climb`), in order. Task 1 is pure data + the simulator (`BattleCatalog`, `BattleSim`, `tools/sim_battle.lua`). Task 2 is the server fight service (`BattleService` keeps one fight per tier in `St.raids[tier]`, the floor or a pocket each; `EventService` becomes the boss rotation; `DataService` saves the reward clocks; `DevService`). Task 3 is the world (`ArenaBuilder` gate zone + dare prompt + a "Raid" pocket kind, `BossBuilder` tier dressing + head tracking). Task 4 is the client (a NEW `RaidGateController` for the idle boss, the gate tag and the dare panel; `ArenaController` loses Join; `BattleController` draws the enrage edges and the lethal telegraph; `SkyController` gets a local raid sky). Task 5 is the tutorial, docs, the rewritten old raid tests and the end-to-end flows. Every task has its own `tools/smoke_raid_*.lua` registered in `tools/smoke.py`.

**Tech Stack:** Roblox Luau written as plain Lua 5.1 (the repo rule), Rojo layout under `src/`, Python 3.12 + lupa for the mock world (`tools/smoke.py`, `tools/robloxmock.lua`), `tools/sim_battle.lua` for balance, `tools/contract.json` + `tools/check.mjs` for the module API contract.

**Spec:** `docs/superpowers/specs/2026-11-01-raid-boss-design.md` (cited below as "spec: Owner's decisions / Starting numbers / Sim targets / Claude's calls / Must keep").
