Gold = `EggStage.Metrics.GOLD`; strokes 4 / 3 px, glow 10 / 6 px at 0.65, notches 16 / 10 px squares at Rotation 45.
  - `HatchLook.TrackFades(track: Frame, color: Color3) -> left, right` two frames "FadeL" / "FadeR" of width 0.12 x the track with UIGradients from `color` to clear.
  - `HatchLook.KEEP` (the set in 16.15), `HatchLook.HideHud(pg: PlayerGui, own: ScreenGui) -> hidden: { ScreenGui }` (disables every Enabled ScreenGui not in KEEP and not `own`, remembers them), `HatchLook.HideOne(gui: Instance)` (the ChildAdded path: the same rule for one gui), `HatchLook.RestoreHud()` (re-enables each remembered gui still parented and still disabled; clears the list), `HatchLook.HiddenCount() -> number` (tests).
